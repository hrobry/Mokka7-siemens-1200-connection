
# Połączenie ethernet pomiędzy Siemens S71200 a aplikacja PC

## Działanie systemu

System działa za pomocą bibliteki Mokka7. Dzięki bibliotece można w łatwy sposób nawiązac połączenie, do tego celu należy umożliwić bibliotece zapisywanie zmian w bazach danych sterownika (DB) a także wyłączyc optymalizacje DB.
Program załącza i wyłącza fizyczne wejscia i wyjścia sterownika oraz umożliwia odczyt danych typu REAL. Na załączonyc filmach widoczna jest praca systemu.
